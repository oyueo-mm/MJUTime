총 62개 자동 검사 통과. 합성 사각형 후보의 마스크 IoU >0.95 검사는 작동 확인이며 실 항공사진 검출 성능으로 해석할 수 없다. 빈 영상은 후보 0개, 해시·날짜·픽셀 크기·권한·행렬 퇴화는 오류로 차단한다. 합성 데이터는 임시 폴더에서 자체 소유 출처로 처리하며 캠퍼스/공식 항공자료로 저장하지 않는다.

`npm run restore:build`는 네 시점에 각각 5/6/7/8개 현재 윤곽 참조 다각형과 건물별 미확인 레코드를 생성했다. 옛 체육관은 모든 출력에서 `geometry:null`. 확정된 과거 형상은 0개다. 정합 5건은 기존 값과 부동소수점 허용 오차 내에서 일치했다. 1985년 값은 픽셀 단위로 유지한다.

Three.js 모델 검사는 네 시점별 Mesh 개수, 유한 좌표, 현재 윤곽 추정 표시, 미확인 객체 생략을 검증했다. UI 상호작용·GPU 실제 렌더·모바일 배치는 브라우저에서 추가 확인해야 한다. 브라우저 설치 실패를 화면 검증 통과로 보고하지 않는다.

원본 사진·대학 PDF·Google Earth 이미지는 새로 커밋하지 않았다. 조사 결과와 코드·생성 참조 데이터만 실험 브랜치에 반영한다. 기존 원시 OSM/정합 파일과 공개 앱 소스·배포 workflow는 수정하지 않는다. 기존 빌드의 500kB chunk 경고는 계속 존재한다.
