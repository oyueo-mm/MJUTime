# 재개 지점 · 2026-10-22

최신 작업 완료: 2006 공간 통합. `INTEGRATION.md` 참고. 기존 geography 엔진이 복원 GeoJSON을 읽고 상세 교사·사진 기반 체육관·운동장/주차 공간을 표시한다. 사용자 체육관 사진 3장은 `.preview/historical-refs/old-gym/`에만 있으며 공개 금지. 날짜/치수 미확인·2002/2006 존치 추정·2007~2009 전환 미확인을 보존한다. 통합 단위 검사·네 시대 동일 카메라·모바일·전체 회귀 및 마지막 영향 범위 재검증/프로덕션 확인을 마쳤다. main/Pages 변경 금지, 기존 generated 파일의 사전 로컬 변경은 덮어쓰거나 커밋하지 않는다. 다음 정확도 과제는 과거 주택가의 실제 윤곽·연대, 체육관의 실측/정확 배치·철거일이다.

2. 구현: MCC 두 홀·중앙 계단·선큰 참조 레벨·단차 옥상·국소 DEM 패치. B2/2F는 원문 확인, 층고·표고·내부 분할은 추정.
