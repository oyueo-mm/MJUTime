# 지도 수정·건축 대조 · 2026-10-23

## 표시 정책

현대 공간 참조(2026 OSM 건물·도로)는 모든 날짜에서 독립 토글이다. `isCurrent`는 수집 월과 일치하는지 알려주는 관측 메타데이터로만 남겼다. 수집 월을 벗어났다는 이유로 도시 배경을 숨기지 않는다. 회색/학교색의 현재 윤곽은 과거 존치 증거가 아니다. 준공 근거가 있는 캠퍼스와 전문대 2동, 홍은2 사업 단계 모델은 별도 날짜 판정을 따르며 참조 토글과 독립이다. 홍은2의 현 건물을 현대 배경과 중복 생성하던 경로도 제거했다.

현재 캠퍼스 구성(MCC 준공 이후)은 상시 라벨을 기본으로 끄고 실제 메시 Raycaster 팝업을 사용한다. 이전 시기에는 주요 역사 라벨을 유지한다. 상시 라벨·변화 마커·현대 참조를 각각 선택할 수 있다. 호버는 드래그 중 숨기고 모바일은 탭으로 상세를 고정한다. 미확인 건물은 이름/용도/준공 미확인을 표시한다. 캔버스만 contextmenu를 취소하고 이벤트 리스너는 종료 시 해제한다.

### 방목 — B: 부분 근거 기반

기존 전체 OSM 압출+일률 창 배열 대신 전용 `bangmok.ts`로 교체했다. OSM 외곽을 기준으로 모서리를 둥글게 다듬고, 낮은 출입 유리층·남측 큰 매스·북측 매스·동측 연결부·열린 공간 위 상부 유리 띠를 따로 구성했다. 녹청 유리, 밝은 층 띠, 가는 수직 프레임, 원형 지지 기둥, 상부 정원과 낮은 채광 구조를 표현했다. 체육관과는 독립 외곽선이다.

사진에서 확인: 곡면 유리 입면, 상부 띠가 빈 공간을 가로지르는 구조, 하부 유리 출입층, 기둥, 보행교와 옥상 식재. 추정: 정확한 곡률·띠 폭·빈 공간의 크기와 좌표·층고·채광창 배치·마감 간격. 현재 DEM에 접합했으나 실제 출입 표고/지하3층 전체를 측량 복원하지 않았다. 그랜드피아노 형태의 인상은 개선했지만 실측 곡면 모델은 아니다.

사진과 동일한 촬영점/렌즈를 맞춘 정합 비교는 아니다. 외부 보행교 전체의 접속부와 전면 캐노피 상세는 미복원이며, 빈 공간과 높이별 매스의 비례도 추가 보정이 필요하다. 지상 가까이에서는 인접 교사에 가려져 확인이 어려웠고, 가까운 사선 뷰에서 곡선/유리/상부 공간을 비교했다.

### MCC — B: 부분 근거 기반

두 덩어리를 같은 깊이로 쌓던 모델에서, 좌측 베리타스 상층 후퇴·지붕 정원·옥상 파빌리온, 낮은 우측 코이노니아와 옥상 운동장으로 구분했다. 중앙의 넓은 계단은 선큰 외부 공간의 층참과 캠퍼스 진입 단차로 나눴다. 아래 외부 정원·테라스와 지붕 운동장이 다른 높이에 있다. 흰 슬래브·수직 기둥·그늘진 유리를 별도 배치했다.

공식 설명의 베리타스 4개 사용층과 건축물대장 B2/지상2층은 서로 다른 기준이며 데이터를 바꾸지 않았다. DEM 국소 패치를 재사용한다. 층고 3.8m, 홀 경계·계단 폭·운동장 치수·출입 레벨·성큰 깊이·대지 절토는 추정이다. 당시 운동장 철거일이나 월별 공정률을 만들지 않았다. 사진의 외형 관계를 반영했지만 정확한 단면·층별 구조를 복원한 결과는 아니다.

낮은 전면 캡처에서는 현재 OSM 주택·아파트가 일부 시야를 가린다. 두 홀/운동장/옥상 단차가 보이는 사선 전체 화면도 함께 제공한다. 전면 정원의 지형·옹벽 및 홀 경계는 공식 단면도에 의한 추가 교정이 필요하다.

## 변화 기록

이전 렌더 월과 새 월 사이의 기록을 양방향으로 찾는다. 같은 위치의 기록은 묶고 다른 기록은 상세에서 선택한다. 화면 밖/중첩 마커는 숨기며 기록 선택 목록에서는 계속 접근할 수 있다. 행정 신고·인가, 실제 시설 기록, 기관 이전을 구분한다. 단순 메시 숨김은 철거 사건이 되지 않는다.

체육관→도서관은 `2006~2010 비교 구간·사건 시기 미확인`이다. 2006 복원 가정과 2010 준공 사이의 조사 범위이지 실제 철거 기간이 아니다. 정확한 월을 배정하지 않았고 자동 사건 이동/월별 눈금에 넣지 않았다. 기존 준공·개관·이전·재개발 출처와 정합 파이프라인을 보존했다.

Playwright 전체 실행 11개 통과 후 시간 한도에 걸린 데스크톱 월별 검사 1개를 240초 한도로 단독 재실행해 통과했다(12개 시나리오). 마지막 라벨 예약 보완은 [데스크톱](screenshots/visual-audit-desktop.json)·[모바일](screenshots/visual-audit-mobile.json) 실제 화면에서 네 시대의 동일 카메라, 체육관/도서관 전환, 마커/라벨 교차 0건, 콘솔 오류 0건을 추가 확인했다.

성능 정책: 건물 메시만 Raycaster 대상으로 캐시한다(도로·등고선·edge helper 제외). 같은 지오메트리/머티리얼을 날짜마다 재생성하지 않는다. 이동/모델 전환은 최대30fps, 정지 지도는12fps이며 숨긴 탭은 그리지 않는다. 그림자 맵은 건물 전환 때 갱신하고 정지/카메라 이동 때 재사용한다. 측정 FPS는 이 상한과 소프트웨어 WebGL 부하를 포함하므로 물리 기기의 최대 GPU 성능으로 해석하지 않는다.
