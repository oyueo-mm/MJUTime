검증일: 2026-10-21 (한국 시간)

## 통과한 검사

- TypeScript strict 타입 검사
- Vite 프로덕션 빌드, base `/MJUTime/`
- Vitest 8개: 개관 연도 경계, 자료 미상 건물 처리, 1979년 이전 용인, 결정론적 왕복, 범위 제한, 사건 이동, 마커 선택, 자료 무결성
- Playwright 6개: 데스크톱 Chromium 3개 + Pixel 7 에뮬레이션 Chromium 3개. 최종 로컬 실행 49.3초, 전체 통과
- npm 의존성 검사: 알려진 취약점 0개

실제 `THREE.Scene`의 건물 scale·가시성, 카메라 좌표, 렌더러 draw calls와 Geometry 수를 읽어 검사했습니다. Canvas 표시만 확인하는 테스트가 아닙니다.

## 표현과 검증의 한계

형태·배치는 시연용 모델이며 역사 복원이 아닙니다. 기본 건물 군은 신축 연도가 없으므로 현재 연도에만 개념 모형으로 표시합니다. 과거의 빈 공간은 확인된 건물이 없다는 뜻이며, 그 장소가 실제로 비어 있었다는 역사적 주장은 아닙니다.

모바일은 브라우저 에뮬레이션으로 검증했습니다. 실물 기기의 발열·배터리·Safari 동작은 추가 확인이 필요합니다. Three.js 배포 청크가 500kB를 넘는 Vite 권고가 있으나 빌드는 성공하며, gzip 기준 해당 청크는 약 181kB입니다.

GitHub Actions는 동일한 타입 검사·단위 테스트·빌드·브라우저 테스트를 실행한 뒤 Pages에 배포합니다. 실제 배포 상태는 저장소 Actions에서 확인할 수 있습니다.
