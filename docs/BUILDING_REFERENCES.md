## 복원 등급

- **A 근거 기반 단순화**: 공식 외관 사진과 배치 자료에서 대표 실루엣·주요 재료 확인.
- **B 부분 근거 기반**: 확인 가능한 매스를 반영했으나 전면·후면·옥상 등 중요한 부분에 제한이 있음.
- **C 개념 모형**: 특정 실재 건물의 정확한 외관을 주장하지 않음.

등급은 **현재 외형**의 신뢰도이다. 개관 연도 검증과 독립적이다. 외형 근거가 있는 종합관 등의 신축 연도가 이번 자료에서 확인되지 않아도 과거에 임의로 표시하지 않는다.
